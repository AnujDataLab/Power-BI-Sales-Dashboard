# Power-BI-Sales-Dashboard
This project is an interactive Sales Dashboard created using Microsoft Power BI.

## Project Overview

The dashboard provides an overview of sales performance and helps analyze revenue, orders, products, regions, and customer trends.
## Key Insights

* Total sales and revenue performance
* Sales by region
* Sales by product category
* Monthly sales trends
* Top-performing products
* Customer analysis
* Interactive filtering using slicers
